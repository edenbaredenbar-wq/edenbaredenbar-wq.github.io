# מסע בישראל · Masa B'Yisrael: Israel Road Trip Race

A projector game for one 35-minute class (ages 16–18). Teams race a vehicle from **Tel Aviv to Eilat** by winning challenges. The teacher runs everything from one laptop.

- The whole game is one file, `index.html`. It has no backend and no build step, works **offline**, and doesn't save anything between sessions.
- The UI is in English. Hebrew appears as flavor only (place names, event cards, a few fun words), always next to the English.
- **Medium difficulty.** Almost every question is multiple choice with realistic wrong answers (other Israeli cities, seas, snacks, kings). Students can get there with general knowledge, the map on screen, or facts from earlier in the trip.

---

## How to run it

1. **Double-click `index.html`.** It opens in any modern browser; Chrome or Edge is recommended.
2. Press **F** for fullscreen and plug in the projector.
3. On the setup screen:
   - Choose **2–6 teams**.
   - Type the team names. Click a vehicle to swap it: 🚐 🐪 🛵 🚌 🚲 🛻.
   - Set the class clock.
4. Click **🚀 Yalla — start the trip!** or press Enter.

The game is also published on the site at `https://edenbaredenbar-wq.github.io/israel-road-trip/`.

Sounds are generated by the browser. Press **M** to mute.

## Teacher controls

| Key | What it does |
|---|---|
| **Space** / Enter | Next step: draw a challenge, start the timer, continue |
| **C** | ✅ Correct |
| **W** | ❌ Wrong. The next team gets one steal attempt. |
| **R** | Reveal the answer. For Charades and Draw It, R starts the "actor peek" instead. |
| **T** | Restart the countdown |
| **1–6** | Final Sprint: the team that buzzed first |
| **N** | Final Sprint: nobody got it, so reveal the answer and move on |
| **P** | Pause or resume everything, including the master clock |
| **U** / Ctrl+Z | Undo the last action. You can press it repeatedly. |
| **F** | Fullscreen |
| **M** | Sound on or off |
| **H** | Keyboard help |

Every key also has a big on-screen button.

## Rules

- **Correct answer:** +10 points and the team's vehicle drives to the next stop. A one-line fun fact about that stop pops up.
- **Wrong answer:** the team stays put, and the **next team may steal for +5 points**. Stealing doesn't move the stealing team.
- **Event cards:** after each turn there's a 25% chance of one.

  | Card | Effect |
  |---|---|
  | 🚗 פקק באיילון (Ayalon traffic jam) | Lose your next turn |
  | 🧆 עצירה לפלאפל (Falafel stop) | Answer a bonus question for double points (+20) |
  | 🐪 גמל חוסם את הכביש (Camel blocks the road) | Swap places with the team behind you |
  | 👍 טרמפ (Hitchhike) | Jump ahead one stop |
  | 🥜 במבה בוסט (Bamba boost) | Your next correct answer counts double |

- **Final Sprint** starts when **5 minutes are left** or **when a team reaches Eilat** (that team also gets +20).
  - There are 5 lightning questions with 3 choices each, and every team gets the same question. They're based on facts from the trip.
  - Teams raise their hands to buzz in, and you press the number of the team that was first.
  - A correct answer is worth +20. A team that answers wrong is locked out, and the other teams can buzz again.
- **Most points wins.** The end screen shows a podium, confetti, and a recap of the stops each team visited.
- You can start the Final Sprint early with the **⚡ Final Sprint** button (click it twice). During the sprint, the same button becomes **🏁 End game**.

### Challenge types

| Type | What happens |
|---|---|
| 🧩 **Guess the Place** | Emoji clues plus a question, with 3 choices to pick from. |
| 🤔 **Israeli or Not?** | A true/false statement about Israeli food, culture, slang or history. |
| 🎭 **Charades** | Secret card, see below. One teammate acts it out and the team guesses. |
| ✏️ **Draw It** | Secret card. One teammate draws on paper (no letters!) and the team guesses. |
| 🔢 **Put in Order** | Four shuffled items. The team answers with letters, e.g. "C, A, D, B". |
| 💡 **Fun Fact Quiz** | Multiple choice, A–D. |

**How the secret card works (Charades / Draw It).** The screen is projected, so the card stays hidden.

1. The actor comes up to the front.
2. Press **R**. The screen tells the class to close their eyes, counts down 3‑2‑1, then shows the card for 5 seconds.
3. The 30-second timer starts automatically.

Every challenge has a visible 30-second countdown; a steal gets 20 seconds. When time runs out, nothing is judged automatically. You still press C or W, so you can be generous.

## How to edit the content

Open `index.html` in any text editor (Notepad, VS Code, TextEdit in plain-text mode). The **first thing in the file** is one clearly labeled object:

```js
const GAME_CONTENT = {
  settings: { ... },     // timers, points, event chance, when the sprint starts
  stops: [ ... ],        // the 10 stops IN ROUTE ORDER, each with a fun fact + challenges
  events: [ ... ],       // the 5 event cards (keep the ids!)
  finalSprint: [ ... ]   // lightning-round questions
};
```

Save the file and refresh the browser. That's all.

### Challenge formats (copy and paste one of these)

```js
// answer must match one of the choices exactly. Leave out choices for an open question.
{ type: "emoji", clue: "🐠🪸🤿", question: "What do people do in Eilat?",
  choices: ["Snorkel on coral reefs", "Surf big waves", "Go whale watching"],
  answer: "Snorkel on coral reefs", note: "Optional fact shown on reveal." },

{ type: "israeliOrNot", statement: "Israelis drive on the left.", answer: false,
  explain: "Israelis drive on the right." },

{ type: "charades", prompt: "Riding a camel that refuses to move" },

{ type: "draw", prompt: "A camel wearing sunglasses" },

// items MUST be written in the CORRECT order. The game shuffles them on screen.
{ type: "order", question: "Put these cities from NORTH to SOUTH:",
  items: ["Nahariya", "Haifa", "Netanya", "Ashdod"] },

// answer is the position of the right option in YOUR list: 0 = first, 1 = second…
{ type: "quiz", question: "Which sea is Eilat on?",
  options: ["The Red Sea", "The Mediterranean", "The Dead Sea", "The Black Sea"],
  answer: 0, note: "Optional extra fact shown on reveal." },
```

Final Sprint questions look like this:

```js
{ question: "Israel’s peanut-flavored snack is called…", options: ["Bamba", "Bissli", "Krembo"], answer: "Bamba" },
```

### Tips

- **Answer order doesn't matter:** quiz options, emoji choices and Final Sprint options are shuffled on screen, so you can always write the right answer first.
- **Adjusting difficulty:** realistic wrong answers ("Haifa / Tzfat / Jerusalem") make a question medium. Silly ones ("A chocolate lake", "Spider-Man") make it easy.

- **Challenges per stop:** add as many as you like. The game rotates challenge types, avoids repeats, and only recycles a stop's challenges once they've all been used.
- **Which stop's challenges are used:** a challenge belongs to the stop the team is **heading to**. Tel Aviv's challenges are used as Falafel-stop bonus questions while a team is still in Tel Aviv.
- **Quotes inside text:** use curly quotes (‘ ’ “ ”) or `\"`. A plain `"` inside a string will break the file.
- **Common settings:**
  - `challengeSeconds: 45` gives more time for drawing.
  - `eventChance: 0.4` makes event cards more frequent.
  - `finalSprintQuestions: 3` makes a shorter sprint.
- **If the game shows a blank page after an edit,** you probably broke a comma or a quote. Undo your last change.

## 35-minute teaching script

The game clock is the lesson clock. Setup takes about 3 minutes, so **set the clock to 32 minutes** on the setup screen. The Final Sprint then starts at about class minute 30, and the podium lands before the bell. If you set up before class, leave it at 35.

| Class time | What happens | Teacher says / does |
|---|---|---|
| **0:00–3:00** | **Hook + teams.** Project the setup screen; the rules are on the right. | "Today we're driving the length of Israel, from Tel Aviv to Eilat — and you're racing!" Split the class into 4–6 teams of 4–6 students. Each team picks a name; type the names in. Set the clock to 32 and press **Yalla!** |
| **3:00–5:00** | **First turn as a demo.** | Read the Tel Aviv fact on the start banner aloud. Draw Team 1's challenge (Space) and talk through the timer and ✅/❌. If the team is wrong, show how the next team steals. "Every turn you might get an Event Card — traffic, falafel, camels…" |
| **5:00–15:00** | **Race, round 1.** Aim for about 1 minute per turn. | Keep it snappy: Space → challenge → C/W → Space. **Read each arrival fact aloud**; that's the learning moment. For Charades/Draw It, call up the actor and press R ("Eyes closed, everyone!"). |
| **15:00–16:00** | **Pit stop.** | Press **P** to pause. Ask: "Which fact so far surprised you most?" Take 2–3 answers, then press P again. |
| **16:00–30:00** | **Race, round 2.** | Let teams choose who acts or draws; rotate so everyone takes a turn. Hype the event cards. Use **U** if you click the wrong button. |
| **≈30:00** | **Final Sprint starts automatically** (5 minutes left, or earlier if a team reaches Eilat). | "Same question for everyone — hands up to buzz!" Press the number of the first team, then C or W. If nobody gets it, press N. |
| **33:00–35:00** | **Podium + wrap-up.** | The podium and confetti appear. Scroll through the **trip recap** and ask each team to name one place they "visited" and one fact they'll remember. Exit question: *"Which stop would you visit first in real life, and why?"* |

**If you're running late:** click ⚡ Final Sprint twice to start it early, or set `finalSprintQuestions` to 3.

**If you're running early:** the race just keeps going. Teams usually reach Beer Sheva or Eilat by the end.
