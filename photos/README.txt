Put the Round 2 ("Chicago or Israel?") photos in this folder.

1. Copy your photos here (JPG, PNG or WEBP all work).
2. Open data.js and, under "round2", set for each photo:
     file:   the exact file name, e.g. "bean.jpg" (capital letters matter!)
     answer: "chicago" or "israel"
     place:  the place name shown on reveal, e.g. "Cloud Gate, Millennium Park"
3. Reload the game page.

If a file is missing or misspelled, the game shows a friendly
"PHOTO COMING SOON" placeholder instead, so nothing breaks.
